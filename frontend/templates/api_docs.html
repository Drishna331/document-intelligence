Endpoint reference

The interactive Swagger UI loads when its CDN is reachable. This endpoint reference and the OpenAPI schema remain available without it.

MethodPathResponse
POST/api/v1/documents/process201 with stored result; multipart file and document_type
GET/api/v1/documents/{document_name}200 with latest result; 404 when absent
GET/api/v1/documents200 with documents, total, limit and offset
GET/api/v1/health200 when database is available; reports processing readiness

Supported types: invoice, balance_sheet, profit_and_loss, cash_flow_statement.

Errors use error.code and error.message. Processing failures use FAILED; financial checks use PASS, FAIL or NOT_APPLICABLE.
